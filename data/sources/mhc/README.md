# Matthew Henry, *An Exposition of the Old and New Testament* (early 18th century; completed by others after his death in 1714)

Public domain. Matthew Henry (1662–1714) was an English Presbyterian (nonconformist) minister.

Each file is one chapter, copied unchanged from https://github.com/lyteword/mhenry-complete
(a Markdown edition that states it changes formatting only). Sentences used on the site were compared
with the same commentary as published by Bible Gateway (https://www.biblegateway.com/resources/matthew-henry/)
and CCEL (https://ccel.org/ccel/henry/mhc1).

The build checks that every English sentence a chapter application relies on (`basis`) appears word for word here.
