# وصف صور الشخصيات (للمولّدات الخارجية)

**طريقة الاستخدام:**
1. انسخ «الأسلوب الثابت» وحطه في آخر وصف كل شخصية، علشان كل الصور تطلع بنفس الشكل.
2. استخدم أي أداة صور زي ChatGPT أو Gemini أو Midjourney أو Leonardo.
3. اختار صورة أفقية (4:3) والوجه في النص.
4. ابعتلي الصورة واسم الشخصية، وأنا أركبها. ولو حبيت تركبها بنفسك:
   `python3 scripts/add-portrait.py moses moses.png`

**قواعد ثابتة:**
- مفيش صورة للمسيح أبداً، ولا في خلفية أي مشهد.
- مفيش هالات ولا كتابة جوه الصورة.
- الملامح شرق أوسطية سامية، مش أوروبية.
- العمر واللبس بحسب نص الكتاب، والشاهد مكتوب تحت كل شخصية.
