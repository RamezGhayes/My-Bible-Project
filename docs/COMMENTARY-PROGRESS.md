## أين تكتب

- التعليقات: `content/books/<slug>/voices/<n>.mjs` (مصفوفة `export default [...]`).
  - جوزيك: `{ r: '1-3', k: 'guzik', sec: 'A1', p: '...' }` (sec = مفتاح قسم في commentary.json).
  - ماك آرثر: `{ r: '1-3', k: 'mac', ser: '42-62', p: '...' }` (ser = كود العظة).
  - `r` لازم يقع داخل مدى القسم/العظة، والبناء يتوقف غير ذلك.
- السجل: `data/sources/commentary.json`
  - `guzik.chapters["luke-5"] = { url, lang: "ar"|"en", secs: { A1: "عنوان القسم", ... } }`
  - `mac.sermons["42-62"] = { t, date, book: "Luke", ch: 5, v: [1, 11], url }`
- ملاحظات القراءة (بصياغتنا، لا نص منقول): `data/sources/guzik/<slug>-<n>.md` و`data/sources/mac/<slug>-<n>.md`.
  اكتب فيها: الرابط اللي اتقرأ فعلاً، وتاريخ القراءة، والعظات المقفولة (robots-blocked) أو اللي ما اتقرتش.
- ملف النموذج: `content/books/luke/voices/5.mjs` مع `data/sources/mac/luke-5.md` و`data/sources/guzik/luke-5.md`.

## القواعد

- لا اقتباس حرفي من جوزيك أو ماك آرثر. تلخيص عربي بصياغتنا، ٢ – ٤ جمل لكل مدخل.
- لا شيء من الذاكرة. لو العظة مقفولة أمام WebFetch: لا مدخل mac لهذا المقطع، واكتب ده في ملف الملاحظات.
- صفحة جوزيك العربي أولاً (`enduringword.com/bible-commentary/ar/<slug>-<n>/`)، ولو مش موجودة الإنجليزي، واكتب `lang`.
- لما رأي المفسر يخالف القراءة المُصلَحة (الصخرة، متى ٢٤، المعمودية، الملك الألفي ...): انقله بأمانة وأضف ملحوظة محايدة بين قوسين.
- لا تنسب للمفسر موقفاً لم تجده في نص العظة نفسه (مثال: حذفنا جملة عن الكفارة المحدودة في متى ٢٠: ٢٨).
- «» فقط لنص فاندايك الحرفي؛ غير ذلك "".
