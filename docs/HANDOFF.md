# تسليم المشروع لجلسة Claude جديدة

هذا الملف للمالك: فيه البرومبت اللي تنسخه وتلصقه في حساب Claude التاني، وتحته القواعد اللي البرومبت بيحيل عليها. اقرأ `PROJECT-LOG.md` للتاريخ الكامل.

## البرومبت (انسخه كما هو)

```
أنت تكمل مشروع موقع دراسة الكتاب المقدس العربي «لمجد الله».
المستودع: https://github.com/RamezGhayes/My-Bible-Project
اعمل على الفرع v5 فقط. لا تلمس main أبداً. لا تدمج في main.

ابدأ بالترتيب ده قبل أي كتابة:
1. git clone ثم git checkout v5.
2. اقرأ بالكامل: docs/HANDOFF.md، ثم PROJECT-LOG.md (خاصة القسمين 2 و18)، ثم docs/design/next-designs.md.
3. شغّل: bash tools/deep/setup.sh ثم node tools/deep/heb-setup.mjs  (اليوناني SBLGNT/MorphGNT وقاموس Dodson، والعبري OSHB/WLC، في .gk/)
4. شغّل: node src/build.mjs && node scripts/check-deep.mjs && node scripts/check-links.mjs && node scripts/check-quotes.mjs
   لازم كلها تطلع 0 problems / 0 broken. لو لا، وقف وقولي.
5. اعرف إيه اللي خلص: ls content/books/*/deep/  . متكتبش أي ملف موجود من جديد.
6. اقرأ ملفين نموذج كاملين قبل ما تكتب: content/books/matthew/deep/26.mjs و content/books/mark/deep/1.mjs.
   ده المستوى المطلوب بالظبط: عمق وطول وصرامة.

المهمة: كمّل الدراسة المتعمقة حسب قسم «المتبقي» في docs/HANDOFF.md:
التكوين ٢٨ – ٥٠ ← باقي العهد القديم بالترتيب، ثم مراجعة المحتوى السابق على المصادر الأولية.
العهد الجديد كله خلص.
القاعدة الجديدة: المصادر الأولية فقط (اقرأ القسم في القواعد الثابتة). كل نسبة لمؤلف قديم أو إقرار ترجع لنصها الأصلي بالموضع.

طريقة الشغل السريعة الدقيقة:
- استخدم وكلاء (subagents) بالتوازي: كل وكيل 4 أصحاحات، 4 إلى 6 وكلاء مرة واحدة.
- كل وكيل يكتب الملفات ويشغّل الفحوصات بس. ممنوع الوكيل يعمل commit أو push أو build.
- أنت (الجلسة الرئيسية) تراجع كل دفعة بنفسك: تشغّل الفحوصات، تقرأ قسم history كله وتتأكد من كل مؤلف وكتاب وسنة،
  تراجع أي ادعاء رقمي أو تاريخي الوكيل قال إنه من الذاكرة، تصلح، ثم commit لكل دفعة وpush على v5.
- اكتب للوكلاء الـ workflow الكامل من قسم «خطوات كل أصحاح» تحت، حرفياً، لأنهم يبدأون من غير سياق.

الدقة اللاهوتية والنصية 100% أهم من السرعة. أي معلومة مش متأكد منها: احذفها أو قلها بتحفظ («على الأرجح»، «يرى بعض الدارسين»).
لما تخلص كل سفر: حدّث سطر «تم:» في PROJECT-LOG.md القسم 18، وابني الموقع وتأكد إن الروابط 0 broken.
اكتب لي التقارير بالعامية المصرية، قصيرة وواضحة.

بعد ما العهد الجديد يخلص (أو لو طلبت): نفّذ التصميمات في docs/design/next-designs.md (الخلوة الجديدة ثم بطاقة الآية)،
وراجعها بلقطات شاشة موبايل وكمبيوتر قبل الرفع.
```

## القواعد الثابتة (لا استثناء)

**المحتوى واللاهوت**
- منظور مُصلَح (إقرار وستمنستر ١٦٤٧ وكالفن)، مع عرض الآراء الأخرى بأمانة وإنصاف في `others` و`issues`.
- كل معلومة عليها وسم: `agreed` متفق عليه، `likely` مرجح، `debated` مختلف عليه.
- لا يُذكر مفسر أو كتاب إلا لو حقيقي ومؤكد: الاسم، والعنوان، والسنة. لو سنة الميلاد مش مؤكدة: `'معاصر'`. بابياس: `'أوائل القرن الثاني'`.
- لا اقتباسات حرفية من المفسرين، بل تلخيص بصياغتنا.
- لا صياغة بنكهة إسلامية. لا شرطة طويلة (—). لا تصوير للمسيح أبداً.
- مسائل النص (اختلاف المخطوطات بين فاندايك والنص النقدي) تُذكر بصراحة في `extra` أو `issues`، من غير تهويل ولا إخفاء.
- الكلام عن اليهود: النقد في الأناجيل نقد نبوي من داخل إسرائيل لقادة جيل معين، وأي استعمال معادٍ لليهود خطأ. قلها حيث يلزم.

**المصادر الأولية فقط (قرار المالك، ٢٠ نوفمبر ٢٠٢٦)**
- كل معلومة تؤخذ من مصدرها الأصلي، لا من مرجع ثانوي ينقل عنه:
  - النص الكتابي: فاندايك (`bk.mjs`)، واليوناني SBLGNT/MorphGNT، والعبري WLC/OSHB، والسبعينية من نصها نفسه.
  - آباء الكنيسة والمصلحون وغيرهم: من كتابهم نفسه، بموضع محدد (الكتاب/الفصل/العظة). مثلاً: أغسطينوس، مدينة الله ٢٠: ١٩، لا "قال أغسطينوس" نقلاً عن تفسير حديث.
  - الإقرارات والمجامع: من نصها الرسمي، بالفصل والفقرة (وستمنستر ١١: ١، ترنت الجلسة ٦، دورت ١: ٧).
  - النقوش والمخطوطات واليهوديات (يوسيفوس، فيلو، المشناه، قمران): من النص الأصلي أو ترجمته، بالموضع.
- العلماء المعاصرون يُذكرون فقط كأصحاب رأي في كتابهم هم (الرأي ينسب لهم بأسمائهم)، ولا يُستعملون مصدراً لمعلومة عن قدماء أو عن النص.
- لو الادعاء مش ممكن نرجع فيه للنص الأصلي ونتأكد منه: يُحذف أو يُصاغ عاماً بلا نسبة. لا نسبة من الذاكرة ولا من مرجع ثانوي.
- للتحقق: النصوص الأصلية متاحة عبر WebFetch (مثلاً ccel.org لآباء الكنيسة وكالفن، newadvent.org/fathers، perseus.tufts.edu، sefaria.org للمشناه والتلمود، نصوص الإقرارات الرسمية). اذكر في التقرير أي ادعاء ما اتراجعش على النص الأصلي.

**علامات التنصيص**
- «» فقط للنص الحرفي من فاندايك (أي طول). يتطابق حرف بحرف مع الآية المذكورة بعده بين قوسين.
- الترجمات والمعاني والعناوين والكلام عن الكلمات: "" .
- ممنوع "..." داخل «». لو عايز تقطع آية: قطعتين «» منفصلتين.
- فاندايك يكتب «يارب»، «ياشيطان»، «ياإلهي» بلا مسافة. انقلها كما هي أو تجنبها.

**اليوناني**
- كل كلمة في `words` (`g`) لازم تكون موجودة فعلاً في SBLGNT في الآيات المذكورة، و`l` جذرها كما في MorphGNT. الفحص يتأكد.
- كل عدد مرات («تأتي ٥ مرات في متى») يُتحقق بـ `count.mjs` قبل كتابته.

```
1) اقرأ فاندايك واليوناني للأصحاح كله.
2) قبل كتابة أي «» تحقق منه بـ v. كل شاهد من العهد القديم أو الجديد يتراجع.
3) اكتب content/books/<slug>/deep/<n>.mjs بنفس بنية ملفات متى (lead, flow{intro,units,threads,note}, verses[] تغطي كل آية مرة واحدة, background, ot, theology, history, issues, teaches, further). كل words.d مملوء. Greek داخل النص يُكتب **هكذا**.
4) node scripts/check-deep.mjs --fix <file>   (يحول «» غير الحرفية إلى "" ويصلح الجذور)
5) راجع اللي اتحول: لو كان نص كتابي، رجّعه «» حرفي مقسوم قطع.
6) node scripts/check-deep.mjs <file> و node scripts/review-check.mjs <file> لازم 0 problems.
7) كل ادعاء عن مؤلف قديم أو إقرار أو نقش أو نص يهودي: ارجع للنص الأصلي نفسه (WebFetch) واذكر الموضع بالضبط. لو مش قادر تتأكد من الأصل: احذف أو عمّم بلا نسبة.
8) لا commit ولا push ولا build. اكتب تقرير: الملفات، عدد الكلمات اليونانية، اللي حذفته لعدم التأكد، ملاحظات النص، وأي ادعاء من الذاكرة لازم يتراجع.
```

## الفروع والتنسيق

- `main`: لا يُلمس.
- `v5`: **الفرع الموحد الحالي** (design-v3 + v4 مدموجين في ٢٠ نوفمبر ٢٠٢٦). كل الشغل الجديد عليه أو على فرع متفرع منه.
- `design-v3` و`v4`: الفرعان القديمان، كل محتواهما داخل v5. لو اشتغلت جلستان في نفس الوقت: كل واحدة على أسفار مختلفة، وقبل كل دفعة `git fetch origin && git merge origin/v5`.
- commit لكل دفعة، والرسالة تنتهي بسطر Co-Authored-By الخاص بالجلسة.
- لا تستعمل أي مفاتيح AWS أو أسرار للمالك. توكن GitHub عند المالك.

## المتبقي (٢٠ نوفمبر ٢٠٢٦)

1. **لوقا:** اكتمل (٢٠ نوفمبر ٢٠٢٦). العهد الجديد كله تم.
2. **العهد القديم:** التكوين ٢٨ – ٥٠، ثم باقي الأسفار بالترتيب (الخروج ← ملاخي).
3. **مراجعة المصادر الأولية:** المحتوى المكتوب قبل ٢٠ نوفمبر راجعناه (أسماء وكتب وسنين وأعداد)، لكن مش كل نسبة اتراجعت على النص الأصلي نفسه. المطلوب مرور على قسمي `history` و`theology` في كل ملف: كل نسبة لمؤلف قديم أو إقرار ترجع لنصها الأصلي بالموضع، والباقي يُعمّم أو يُحذف.
4. **التصميمات:** الخلوة بأربع خطوات (اقرأ ← افهم ← اربط ← تأمل وصلِّ) وبطاقة دراسة الآية، حسب `docs/design/next-designs.md`.
5. **إرميا ٥ وما بعده** (صفحات الخلوة): متوقف.

## الشكل التقني للدراسة المتعمقة

- الملف: `content/books/<slug>/deep/<n>.mjs` (slug مثل `john`, `1-corinthians`).
- البناء يولّد `dist/book/<slug>/<n>-study.html` تلقائياً لو الملف موجود، ويضيف زرار «خلوة | دراسة متعمقة» في الصفحتين.
- الرسم: `deepPage` في `src/build.mjs`، والتنسيق في آخر `src/v2/assets/v3.css` (`.dmode`, `.dwrap`, `.dtoc`, `.dsec`, `.dv`, `.dw` ...).
- لقطات الشاشة: `(cd dist && python3 -m http.server 8765 &)` ثم `node tools/deep/shot.mjs` (يحتاج playwright وgoogle-chrome).
