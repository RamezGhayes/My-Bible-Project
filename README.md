# موقع دراسة الكتاب المقدس

موقع ثابت (Static) لدراسة الكتاب المقدس سفراً سفراً وإصحاحاً إصحاحاً، بالعربية ومن منظور مُصلَح.

## تغيير اسم الموقع

كل بيانات الهوية في ملف واحد: `site.config.json`. غيّر `name` و`nameAr` و`tagline` ثم أعد البناء، فيتغير الاسم في كل الصفحات.

## البناء

```
npm run build          # يبني الموقع كاملاً في dist/
node scripts/check-quotes.mjs   # يتحقق أن كل «اقتباس» كتابي مطابق لنص فاندايك
node scripts/check-links.mjs    # يتحقق من كل الروابط الداخلية
```

لا يحتاج المشروع أي مكتبات خارجية، فقط Node 18 أو أحدث.

## النشر على Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`

## أين المحتوى؟

- `data/bible/`: نص فاندايك (1865، ملكية عامة) بكل التشكيل، ملف لكل سفر.
- `data/books.json`: بيانات الأسفار الـ66.
- `content/books/<السفر>/intro.mjs`: مقدمة السفر (سبعة أجزاء).
- `content/books/<السفر>/chapters/<رقم>.mjs`: دراسة الإصحاح.
- `src/`: محرك البناء والقوالب والتصميم.

الآيات في المحتوى تُكتب كمراجع (`Matt.5.3-12`) ويُسحب نصها تلقائياً من فاندايك، فلا يُكتب نص الكتاب يدوياً.
